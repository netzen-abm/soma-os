# SOMA-OS Evidence Sources

This directory contains source assessments, evidence contracts, benchmarks, and migration/research source material.

## Boundary

An evidence-source document records or evaluates evidence. It does not itself grant clinical authority. Canonical evidence semantics live in the Health Evidence Graph and related schemas.

## Key artifacts

- Source/provenance contracts
- Claim schemas and canonical mappings
- Study evidence extraction contracts
- Research benchmarks
- Source-specific assessments
- Publication and migration gates

## Evidence discipline

Preserve source identity, provenance, retrieval context, limitations, contradiction, uncertainty, safety, and applicability. Do not treat duplicate provider records as independent evidence.
